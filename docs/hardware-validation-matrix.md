# 硬件兼容性验证矩阵

这份矩阵用于记录随芯调在真实 Windows 设备上的验证结果。它是发布和启用高风险能力前的证据清单，不代表仓库当前已经完成所有实机验证。

## 结果状态

| 状态 | 含义 |
| --- | --- |
| `未执行` | 尚未在目标设备上运行，不能据此判断支持或不支持。 |
| `通过` | 核心行为、降级行为和回滚行为均符合验收标准，并留有证据。 |
| `降级通过` | 核心调度可用，但某些硬件能力不可用；界面必须显示明确原因。 |
| `阻止` | 检测到不安全或不可验证条件，相关写入能力必须保持关闭。 |
| `失败` | 运行结果不符合验收标准，必须保留日志和复现步骤。 |

禁止把“Provider 能加载”“WMI 有返回值”或“程序没有立即崩溃”单独记为通过。

## 核心矩阵

| 编号 | 场景 | 最低覆盖范围 | 重点观察 |
| --- | --- | --- | --- |
| HW-01 | Windows 平台 | Windows 11 x64，普通用户和管理员各一次 | 启动、能力检测、前台识别、日志和退出回滚。 |
| HW-02 | CPU 平台 | Intel、AMD 各至少一台 | 电源方案切换、高级处理器设置、恢复原值。 |
| HW-03 | GPU 厂商 | NVIDIA、AMD、Intel 各至少一台 | 适配器识别、只读遥测、厂商 Provider 降级状态。 |
| HW-04 | 混合显卡 | 核显 + 独显，独显直连和混合输出 | 前台 GPU 指标归属、多适配器汇总、无伪造零值。 |
| HW-05 | 显示与图形栈 | 单显示器、多显示器、HAGS 开启/关闭 | GPU Engine 计数器、PresentMon 冲突和取消清理。 |
| HW-06 | 供电状态 | 接电、拔电、快速切换供电 | AC / Battery Profile 选择、失败回退和日志原因。 |
| HW-07 | 前台生命周期 | 切换窗口、进程退出、PID 复用、窗口短暂不可用 | 不误调新进程、不残留旧进程状态、会话去重。 |
| HW-08 | 系统生命周期 | 睡眠/唤醒、锁屏/解锁、重启、异常结束 | 启动恢复、待回滚状态、自动调度保护。 |
| HW-09 | 负载场景 | 游戏、浏览器、编译、录制/语音、下载多开 | 前台优先、后台分类、资源争用只在证据充分时给建议。 |
| HW-10 | 传感器缺失 | 无热区、无 GPU 计数器、无 NVML、权限不足 | 独立降级，不显示伪造温度/功耗/频率。 |

## 安全验收

- 原始电源方案、处理器高级设置、前台优先级和后台调整都能读回并恢复。
- 能力检测失败、设备不匹配、权限不足或回滚状态不可读时，不执行新的系统写入。
- GPU 未明确声明可应用能力时，只允许设备识别和只读遥测；电压偏移、曲线和超频写入保持关闭。
- Provider 超时、采样无数据、PresentMon 已被其他工具占用时，不把缺失数据当成 0，也不触发自适应调节。
- 进程退出、PID 复用或前台短暂不可用时，不把旧进程的策略应用到新进程。
- 关闭自动调度后，静态 Profile、诊断观察和回滚入口仍能独立工作。
