# 社区服务端边界

随芯调采用单仓库结构：`客户端/` 是 Windows WPF 应用，`服务端/` 是社区 API。客户端负责本机能力检测、Profile 匹配、系统调度和回滚；服务端只负责社区资源目录、版本信息和后续审核流程。

## 第一阶段

- 提供版本化只读 API：应用 Profile、机型策略包、目录清单和健康检查。
- 使用服务端独立样例目录，并为目录读取、过滤和损坏根节点提供回归测试。
- 服务端样例数据与客户端运行时配置分离，客户端不会把服务端目录当作本地已启用配置。
- 所有社区资源进入客户端后仍必须经过客户端安全校验，并默认禁用。

## 后续阶段

- 账号与权限：作者、审核员、管理员分权。
- 提交审核：上传包、格式校验、恶意字段检查和人工审核队列。
- 可信元数据：作者签名、设备匹配度、驱动/BIOS 范围、风险等级和复现结果。
- 资源统计：下载量、安装量、回滚率和用户反馈。
- 客户端同步：ETag/版本缓存、断点下载、校验和以及失败回滚。

服务端不会执行客户端的电源、进程优先级、GPU 或电压操作，也不会接收用户的本机运行数据作为默认公开内容。
